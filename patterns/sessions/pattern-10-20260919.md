# Pattern 10 - reduced relative clause (second pass)

Date: 2026-09-19 | Pattern: P008 | Status: done | Rounds so far: 3

Second drill on P008, requested by the learner. The first pass (Drill 08) found
the adjective/PP branch landed cleanly and the one miss was a type never taught:
the object-relative drop (`the API which we replaced` -> `the API we replaced`).

Two things happened since:

- Day 18, unprompted in chat: *build a new feature in a project you arent
  familiar with* - the object-relative drop, produced in the wild. Logged
  `pattern-used` (1/2). The untaught type arrived anyway.
- Day 18 also produced a misuse of the -ing reduction: *an engineer knowing much
  is popular in the job market* - `knowing much` is not idiomatic English for
  `who knows a lot`. The reduction was applied where a full clause was needed.
  This drill attacks that boundary.

Round 1 spreads four types again, now including the object drop.
Round 2 carries the Day 18 boundary (when NOT to reduce) plus the P007/P002
tie-ins.
Round 3: free production, 4 items.

The rule extension for this drill:

  Three types, three mechanisms:

  1. who/which + be + X        ->  drop who/which + be        the engineer responsible
  2. who/which + lexical verb  ->  verb becomes participle    the change touching core logic
  3. which/that + S + V        ->  pronoun vanishes            the API we replaced

  Type 2 has a boundary the first drill did not name: the participle must be one
  English actually uses as an adjective. `touching`, `working`, `heading` are
  fine. `knowing much`, `having a rig`, `being an engineer` are not - stative
  verbs resist the reduction. Test: can you put the participle before the noun?
  `the touching change` sounds odd but parses; `the knowing engineer` does not
  mean `the engineer who knows`.

## Round 1 - reduce, pick the right type

**1.** The engineer who is responsible for the feature ends up dealing with it. (type 1)
**中文：**负责这个功能的工程师最终会来处理它。

**2.** The meeting which was held last week decided the framework. (type 1, past participle)
**中文：**上周开的会定了框架。

**3.** The API which we replaced was much cheaper. (type 3 - the Drill 08 miss)
**中文：**我们换掉的那个 API 便宜得多。

**4.** The ticket which the PM assigned to me involves core logic. (type 3)
**中文：**PM 派给我的那个 ticket 涉及核心逻辑。

## Round 2 - mixed, reduce or refuse

**1.** An engineer who knows a lot is in demand in the job market. (careful - Day 18)
**中文：**懂得多的工程师在就业市场上很吃香。

**2.** The projects which were unrelated made the weekly meeting pointless. (type 1)
**中文：**那些不相关的项目让周会失去了意义。

**3.** The error which we found in the logs came from the SMS provider. (type 3)
**中文：**我们在日志里发现的错误来自短信供应商。

**4.** A rig which can run anything is gathering dust. (careful - can this reduce?)
**中文：**一台什么都能跑的机器在积灰。

## Round 3 - free production

**1.** Describe the framework decision your team made last week.
**中文：**说说你们团队上周定的框架。

**2.** Explain what kind of engineer is popular in the job market. (Day 18 retest)
**中文：**说说什么样的工程师在就业市场上吃香。

**3.** Talk about the coupon incident: what was wrong with the amount on the page?
**中文：**说说优惠券那次事故：页面上显示的金额出了什么问题？

**中文：**说说你怎么处理那些太难的书。
