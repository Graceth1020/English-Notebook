# Pattern 18 - abstract prepositions (fourth pass, all-new items)

Date: 2026-10-23 | Pattern: P014 | Status: done | Rounds so far: 3

Requested by the learner ("begin today''s pattern P014 drill... the questions
should never appear before"), overriding `pattern-next`, which had offered
P003. Learner''s pick wins; P003 stays parked.

Constraint honoured: every item is new. Items used in Drills 15/16/17 were
listed first and excluded - no Rednote recipes, no GitHub issues/frameworks,
no line 42, no page 57, no dashboard alerts, no sprints, no root-cause-of,
no scheduled-for stacks.

Spine of this drill, from the Drill 17 carry-forward:

1. **Pin the `with` tool slot.** Drill 17 missed it in Round 1 (`by a single
   command`) and dodged it in Round 2 (converted the tool to a method). This
   time the cue is unambiguously a physical tool (item 1.1) and a SQL query
   (2.1) - no part-whole or method reading available. Discriminating item
   first, per the standing rule.
2. **Retest `by -ing` with no `of` reading.** Drill 17 item 1.8 failed
   because `the cost of switching` is a real phrase. Item 1.2 here
   (`save an hour by taking the expressway`) has no plausible part-whole
   reading.
3. **New fixed collocation: `down to`** (归因于). `thanks to` and `lie in`
   were produced in Drill 17; `down to` has only ever been accepted, never
   requested.
4. Sentinel platforms still checked, but on fresh platforms (Stack Overflow,
   Bilibili) so the surface metaphor - not the memorised phrase - does the
   work.

Round 1 spreads eight distinctions: with-tool / by-ing / on-platform /
off-platform / in-container / of-part-whole / on-topic / at+by time.
Round 2 embeds in sentences, all new scenes.
Round 3: free production, 4 items, scenes not used in any previous drill.

## Round 1 - pick the preposition

**1.** loosen the screw ___ a screwdriver  (pinned tool slot - discriminating item)
**中文：**用一把螺丝刀拧松螺丝

**2.** save an hour ___ taking the expressway  (by -ing, no of-reading)
**中文：**走高速能省一小时

**3.** an answer ___ Stack Overflow  (platform sentinel, fresh platform)
**中文：**Stack Overflow 上的一个回答

**4.** got the idea ___ Bilibili  (off-pair, fresh platform)
**中文：**从 B 站得来的灵感

**5.** a typo ___ the error message
**中文：**报错信息里的一个拼写错误

**6.** the last ten minutes ___ the meeting
**中文：**会议的最后十分钟

**7.** an article ___ spaced repetition  (on = topic)
**中文：**一篇关于间隔重复的文章

**8.** ___ sunrise / ___ the end of October
**中文：**在日出时 / 在十月底之前

## Round 3 - free production

**1.** Tell a teammate how you made the interface faster: what tool you used, what method.
**中文：**跟同事说你怎么把接口提速的：用了什么工具，用了什么方法。

**2.** Recommend something you found on Bilibili or in a podcast - where you saw it, where you got it.
**中文：**推荐一个你在 B 站或播客上发现的学英语的东西：在哪看到的，从哪弄到的。

**3.** Describe the last few days of your sprint: what you were rushing, when the deadline was.
**中文：**说说你这个冲刺的最后几天：在赶什么，截止日期是什么时候。

**4.** Explain why the release went smoothly - what it came down to, what helped.
**中文：**解释这次发布为什么顺利：归因于什么，多亏了什么。
