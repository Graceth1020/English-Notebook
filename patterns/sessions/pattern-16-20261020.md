# Pattern 16 - abstract prepositions (second pass)

Date: 2026-10-20 | Pattern: P014 | Status: done | Rounds so far: 3

Second drill on P014, requested by the learner the day after the first pass
(Drill 15, 10/13). That drill proved the spatial-metaphor procedure works -
metaphor-guided items went 9/10 - and left three flagged misses, which are the
spine of this drill:

1. **Platform-as-container** - `a recipe in Rednote`. The Chinese default reads
   a platform as a box you look inside; English reads it as a surface things
   sit on. The one systematic miss in Drill 15, placed early here per the
   standing rule.
2. **Fixed collocations not reached** - `rely on` was cued and not produced;
   `depend on` was self-produced in Round 3. The metaphor covers ~90%; this
   drill spends more weight on the other 10%.
3. **`by` + bare noun** - `He speeds it up by cache`. `by` + bare noun is
   transport/means only (by bus, by hand). A tool takes `with`, a method takes
   `by -ing`.

Fresh material from Days 32-36 where possible: the JeecgBoot framework project,
the dashboard, the canteen promotion, Rednote recipes.

Round 1 spreads eight prepositions (on/in/of/at/for/by/with/off) with the
platform item at #1 - discriminating item early.
Round 2 embeds in sentences, carrying all three retests.
Round 3: free production, 4 items.

The rule, restated with the Drill 15 additions:

  on = surface/line    a comment on line 42, on the dashboard, on Rednote
  in = container       in the save function, in October, in progress
  of = part-whole      the root cause of the incident
  off = the off-pair of on (platforms)   I got this off Rednote

  PLATFORMS ARE SURFACES: on Rednote / on GitHub / on the platform / on the
  internet - never "in".

  by + bare noun = transport/means ONLY (by bus, by hand)
  tool   -> with          speed it up with the cache
  method -> by -ing       speed it up by caching

  Fixed collocations ignore the metaphor: rely on, depend on, lie in,
  thanks to, down to, based on - learned one by one.
