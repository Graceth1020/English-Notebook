## The Rule

on = surface/line, in = container, of = part-whole. Platforms are SURFACES:
on Rednote / on GitHub - never "in". The off-pair of on is off, and which
pair fires follows the VERB: see/read ON a platform, get OFF it.

by + bare noun = transport/means only (by bus, by hand). A tool takes `with`;
a method takes `by` + -ing; a deadline takes `by` + time.

Fixed collocations ignore the metaphor: rely on, depend on, lie in,
thanks to, down to, based on.
