Checking the corpus before the drill corrected the inventory row: the `-ed` branch

## The Rule

`who/which/that + be` drops both words, keeping whatever follows `be`:

```
the engineer who is responsible     ->  the engineer responsible      (adjective)
the amount which was displayed      ->  the amount displayed          (past participle)
the cars which were heading         ->  the cars heading              (-ing)
the teammate who is in charge of it ->  the teammate in charge of it  (prep phrase)
```

**One test covers all branches: after the reduction, no finite verb may be left
standing.** `responsible` and `displayed` are not finite; `works` and `can run`
are.

Three reduction types:

```
1. who/which + be + complement    ->  drop who/which + be             (Round 1)
2. who/which + lexical verb       ->  verb becomes a participle       (Round 2)
3. which + subject + verb         ->  object pronoun just vanishes    (Round 2)
```

Type 3 is the one the learner had not seen: `which` as the object of the verb
(`we replaced the API`), not the subject. It drops with no verb change.

### What cannot reduce

`who/which + a lexical verb` does not drop to nothing - it strands a finite verb:

```
✗ a rig can run anything                    (from: a rig which can run anything)
✗ the engineer works on payments is on leave
```

## What Went Wrong

- **One miss in twelve, and it is a reduction type that was never taught.** Item
  2.4 (`the API which we replaced`) kept the full clause because the drill had
  only shown subject-relative reductions (`who/which + be` and lexical verbs to
  participles). The object-relative drop - `which` as the object of the verb,
  vanishing with no other change - is a different mechanism, and the learner had
  no reason to reach for it. Not a wrong model producing wrong answers; a model
  that was never offered.

- **A framing error in the drill instructions.** The round was announced as "two
  can reduce, two cannot." The actual split was three reducible, one not. The
  learner's answer was better than the framing: he correctly reduced both lexical
  verbs (2.2, 2.3) and correctly refused the modal (2.1). The miss (2.4) was on
  a type the framing had not prepared him for.

- **A passive-voice slip in Round 3** (3.3): `when the weekly meeting held` for
  `was held`. Not a relative-clause error, but worth noting because it is the same
  `be`-dropping instinct that makes the reduced relative work - applied one clause
  too early, where `be` is still load-bearing.

## The Pattern Behind The Pattern

Sixth drill, and the shape is consistent: Round 1 clean, Round 2 carries the one
miss, Round 3 clean. The miss in Round 2 was on a type that was never taught,
which is a drill-design issue rather than a learning issue. The standing rule -
**one discriminating item is worth four redundant ones** - applied here would have
put the object-relative drop in Round 1, where it could have been corrected and
retested.

What is new: this is the first drill where the learner's corpus already contained
evidence against the inventory row (the `-ed` branch was present in Day 17). The
gap statement was corrected before the drill rather than after, which is the
process working as intended.

## Carry Into Chat

1. Watch for the adjective/PP branch in chat: *the engineer responsible for X*,
   *the teammate in charge of Y*. These are the forms that were missing and are
   now drilled.
2. The object-relative drop (`the API we replaced`, `the book I bought`) is worth
   watching for but was not drilled - if it appears unprompted, log it.
3. The `be`-dropping instinct that makes this pattern work also caused 3.3's
   `when the weekly meeting held`. If a passive `was` goes missing in chat, log
   it as a separate error - it is not the pattern.
