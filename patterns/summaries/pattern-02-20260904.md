# Pattern 02 - purpose nouns

Date: 2026-09-04 | Pattern: P003 | Rounds: 3 | Items: 12 | Correct: 10/12

## The Gap

Zero uses in 45 exchanges. The default is a relative clause - *a platform where we
can get various recipes* - or a bare noun with the purpose left out entirely. Both
are correct, so this could never appear as an error; it is absence, not fault.

Requested by the learner after the `about` vs stacked-noun distinction came up in
conversation.

## The Rule

**Something built for a purpose stacks the purpose noun in front.**

```
a system for learning            ->  a learning system
a platform for booking tickets   ->  a booking platform
a platform for sharing recipes   ->  a recipe-sharing platform
```

`about` is for **content** - what a book, talk, or discussion is *about* - and
never stacks:

```
a book about investing     ->  stays as it is
a podcast about remote work ->  stays as it is
```

The faster test, which turned out to be the one that matters:

> Can you say **"it is for ___-ing"**? -> stack it.
> Can you only say **"it is about ___"**? -> use `about`.

This beats asking "is it a tool", because the failed item was a classification
slip rather than a grammar one - an app was read as a topic instead of a thing
built for a job.

**3.** 一个发短信的服务

**中文：**一个发短信的服务

**You wrote:**
> a SMS-sending service

**Answer:**
> an SMS-sending service

**Verdict:** wrong form

**Why:** The stack is right; the article is not. `a` vs `an` follows pronunciation, not spelling - `SMS` opens on /e/, so it takes `an`. Same class: `an FBI agent`, `an hour`, `an MBA`; and inversely `a university`, `a European`, both opening on /j/.

## Round 2 - stack it, or use about

**1.** 一本讲投资的书

**中文：**一本讲投资的书

**You wrote:**
> a book about investing

**Answer:**
> a book about investing

**Verdict:** ok

**Why:** Content, so no stacking. Trap correctly refused.

---

**2.** 一个学投资的 App

**中文：**一个学投资的 App

**You wrote:**
> an APP about learning investing

**Answer:**
> an investing app

**Verdict:** wrong form

**Why:** The one stackable item hidden among the traps. An app is built to do a job, not to discuss a topic - it is *for* investing, not *about* investing. Two side notes: `APP` in capitals is a Chinese-internet convention, English writes `app`; and `learning investing` collides two `-ing`s, which is why native usage drops one. `an app for learning to invest` is also entirely correct, just uncompressed.

## Round 3 - free production

**1.** Someone asks what Rednote is. Introduce it.

**中文：**有人问你小红书是什么，你介绍一下。

**You wrote:**
> Rednote is a life-sharing platform.

**Answer:**
> Rednote is a life-sharing platform.

**Verdict:** ok

**Why:** Built a compound that was never taught, and it is idiomatic.

**2.** Tell a colleague you have something that monitors whether a service is down.

**中文：**跟同事说你们有个东西能监控服务挂没挂。

**You wrote:**
> We've got a monitoring dashboard to check whether the service is down.

**Answer:**
> We've got a monitoring dashboard to check whether the service is down.

**Verdict:** ok

---

**3.** Explain what you use to learn about investing at weekends.

**中文：**解释你周末学投资都用什么。

**You wrote:**
> Xueqiu is an investing app which helps me keep an eye on development trends from different industries.

**Answer:**
> Xueqiu is an investing app that helps me keep an eye on what's happening across different industries.

**Verdict:** ok

**Why:** Pattern correct, and it is the exact phrase missed in 2.2, self-corrected with no prompting. Not counted against the pattern: `which` -> `that` in a defining clause is the more common spoken choice, and `development trends from different industries` is a shade written for speech.

## What Went Wrong

- **`a` before `SMS`** (1.3) - article choice follows sound, not spelling. Fixed by
  the learner himself in 2.4 without being told.

- **An app classified as a topic** (2.2) - the only substantive miss, and it was a
  classification slip rather than a grammar one. "Is it a tool?" turned out to be
  the wrong question; **"can you say it is *for* ___-ing?"** is the test that would
  have caught it, and it has been written into the rule above.

- **Nothing wrong in Round 3.** The round that predicts real use was clean, and one
  answer invented an untaught compound (`a life-sharing platform`).

## The Pattern Behind The Pattern

Second drill running, the same shape has appeared:

| Drill | Round 1 | Later rounds |
| --- | --- | --- |
| 01 `with X doing` | all four trailing the phrase - old habit wearing new structure | 2.3, 2.4 and all of Round 3 fronted, unprompted |
| 02 purpose nouns | `a SMS`, and an app read as a topic | both fixed in later rounds with nothing said |

The first instinct reaches for the old shape; the second attempt switches. That
argues the bottleneck is not knowledge and not rules - it is **the number of first
instincts he gets to have**. Which is an argument for more items per round rather
than more explanation per item, and for keeping Round 3 large in future drills.

## Carry Into Chat

Watch for these in later sessions, and log `pattern-used` on an unprompted stack:

1. Describing any app, site or internal tool - *a recipe-sharing platform*, *a
   monitoring dashboard*, *an investing app*.
2. Work systems, where the stack often runs three or four nouns deep - *an SMS
   service test script*, *a notification provider*.
3. The trap side is worth watching too: a book, podcast or meeting stays on
   `about`, and over-applying the stack would be a new error rather than progress.

`drilled`, not `owned`. Two unprompted uses in a normal five-exchange chat earn
`owned`, logged with `pattern-used`.
