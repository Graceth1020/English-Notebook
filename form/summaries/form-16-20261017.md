## Round 1 - fixing a bug, ticket to production (past frame)

**Prompt:** Walk me through how you fix a bug - from getting the ticket to verifying the fix in production. 6-8 sentences.

**中文：** 讲一遍你修 bug 的完整流程，从拿到工单到在生产环境确认修复。6-8 句。

**He wrote:**
> I got assigned a ticket last week. I checked the logs for stack traces to locate where the faulty code snippet was and tried to reproduce it locally. After I had located the problem, I added a fix and covered it with a test. Once all test suites were passed, I committed the change and pushed my branch. Before deploying the fix to production, I opened a pull request, got it approved and merged into main. Finally I verified it on the dashboard.

**tense:** ok
**article:** "all test suites" -> "all the tests / the whole test suite" (the narrator's own test suite is specific; the all-sets pattern, second scene)
**form:** "Once all test suites were passed" -> "Once all the tests passed" (pass as in succeed is intransitive; Chinese 测试被通过了 licenses a passive that English does not)
**object:** ok
**prep:** ok

**Note:** Not counted. Self-repair between drafts: the first version had try and
push in present inside the past frame; both were corrected to tried / pushed
before submitting. The skeleton was genuinely native-shaped: Before deploying
..., I opened ..., got it approved and merged into main. Past perfect correctly
deployed in After I had located the problem. Connector quota met: zero then,
After / Once / Before, one purpose link.

## Round 2 - reviewing a pull request (general process, present frame)

**Prompt:** Walk me through how you review someone's pull request, 6-8 sentences.

**中文：** 讲一遍你给别人做 code review 的流程，6-8 句。

**He wrote:**
> Whenever I get tagged as a reviewer, I pull the branch locally and skim the diff. If I find something unresonable, I leave a comment on that line or snippet. Once I've reviewed all changes and there are some unreasonable logic needs to be adjusted, I request changes. Last week I pushed back on a request because of an edge case. When the author addresses my comments, I review it again. I resolve the threads until I approve and sign off.

**tense:** ok
**article:** "all changes" -> "all the changes" (third instance of all + bare plural for the narrator's own specific items: all sets x2, all changes; row opened - chat:E074)
**form:** "unresonable" -> "unreasonable" (spelling); "there are some unreasonable logic needs to be adjusted" -> "there's some logic that needs adjusting" (logic uncountable takes is; the needs-clause dangles without that - the one-verb-per-clause mechanism, chat:E059 family); "I resolve the threads until I approve" -> "... and then approve" (until means up-to-the-point: resolving over and over until approval; the intended order is resolve first, then approve)
**object:** ok
**prep:** ok

**Note:** Not counted. The frame control was adult: a general present
(Whenever / If / When) with a specific past example inserted under an explicit
marker (Last week I pushed back ...) and back out again - licensed switching,
not drift. All four review-flow chunks taught mid-drill came out correct:
leave a comment on that line, request changes, resolve the threads, approve
and sign off. The mid-drill micro-lesson on there's some logic (one verb per
clause) was asked and answered inline. Connector quota met: zero then, four
subordinators, one causal.

## Round 3 - a production incident (past frame; the frame experiment)

**Prompt:** Walk me through one specific incident you handled - from getting paged to the postmortem. Past tense. 6-8 sentences.

**中文：** 讲具体某一次线上事故的处理过程，从被叫起到复盘。用过去时，6-8 句。

**He wrote:**
> At midnight of last Saturday, I got paged because of a production incident. I joined the channel and checked the monitoring dashboard at the same time. Then I checked the logs to narrow it down to the latest deploy which we shipped just now. We talked it through in the channel and decided to roll back the release. After confirming the metric recover, I shipped a hotfix. We ran a postmortem on Monday morning to summarize the experience. I documented the root cause and shared the action items with my teammates.

**tense:** "which we shipped just now" -> "which we had just shipped" (just now anchors to speech-now; the story's anchor is in the past - the main-clause verbs all held, the time anchor defected first); "After confirming the metric recover" -> "the metrics had recovered" (subordinate verb stayed in base form; metric -> metrics)
**article:** ok
**form:** ok
**object:** ok
**prep:** "At midnight of last Saturday" -> "At midnight last Saturday / Last Saturday at midnight" (time phrases chain directly, no of)

**Note:** Not counted. Seven determiners all correct (a production incident /
the monitoring dashboard / the latest deploy / the release / a postmortem /
the root cause / the action items). talked it through produced correctly -
the exact chat:E055 item (talked this though) now right, spelling included.
shared the action items with my teammates used the mid-drill lesson verbatim.
Not counted: summarize the experience -> go over what happened. Connector
quota met: one then, After, two purpose links, one causal.

## What It Showed

**1. The frame experiment concluded, and the hypothesis needs one refinement.**

Drill 13 proposed opener-determines-frame. This drill ran the missing cell
(past opener, past story). Result: with a past opener, every main-clause verb
held - ten for ten across Rounds 1 and 3. The two slips were not main-clause
verbs: a speech-anchored adverbial (just now) and a subordinate-clause verb
(the metric recover). Refined rule: **the opener sets the frame for main
clauses; time adverbials and subordinate verbs are anchored separately and
drift independently.** The teaching target shifts from "pick a frame" (he can)
to "anchor the subordinates to the story's now" - just now -> just / earlier,
and the subordinate verb takes the frame's past.

**2. chat:E074 opened: all + bare plural for the narrator's own items.**

all sets (Drill 14 R1, R2), all test suites (R1), all changes (R2) - four
instances, one mechanism: the items are in front of the narrator and feel
definite, but the all swallows the determiner slot. Distinct from E072
(first-mention the) and E031 (empty slot before singulars): this is a
quantifier masking the slot. Opened at 1 hit with the back-catalog as
evidence.

**3. Article otherwise clean in a scene full of fresh objects.**

Excluding the E074 cells, article was near-perfect: seven correct determiners
in Round 3 alone, second-mention discipline held (the release, the root
cause), first mentions with a. The Drill 15 downgrade to passive watch holds.

**4. The work scene is the chunk-library's richest soil so far.**

Every bank family landed: bug-fix flow (reproduce, cover it with a test, open
a pull request, merge into main, verify on the dashboard), review flow (all
four taught items produced), incident flow (got paged, narrow it down, roll
back the release, run a postmortem, share the action items). And the register
transfer works both ways: talked it through, an old chat error (E055), came
out correct inside a drill - drill production feeding chat repair.

**5. form-axis misses in the work scene are clause-architecture, not words.**

were passed (passive calque), there is some logic needs (stacked verbs),
until for and-then (logic connector) - all three are about how clauses fit
together, the same family the chat track sees constantly. The work scene is
where drill and chat problems finally look identical.

## Carry Forward

   take the story's time, not speech time. One drill round with deliberate

2. **chat:E074 watch in chat:** all + bare plural. The check: "all swallows
