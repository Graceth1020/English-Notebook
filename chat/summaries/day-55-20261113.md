## Questions About English

These did not count as exchanges.

**Q:** At this time 这个词组应该怎么用

**A:** `at this time` = 目前、此刻，公告腔（At this time we are not accepting new orders.），不是「这次」。this time = 这次；at the time = 当时；at this time = 目前。

**Q:** at this time 再多给点例句

**A:** 坐标不同：`this time` 是多次中的这一次，`at this time` 是现在这个时刻（≈ right now）。能换成 right now 就是 at this time，句子里有"与上次对比"就是 this time。

**Q:** "Some goods still haven't been sent by then." 可以吗

**A:** 不行。`by then` = 到那时，必须挂在已说好的时间点上（过去或未来），常配过去完成/将来完成；指"到现在"要用 yet / so far。still 与 yet 不叠用。

**Q:** What's the meaning of "how long before it pays off"?

**A:** `how long before + 从句` = 还要多久才……；`pay off` = 回本 / 见效 / 还清。更口语的说法是 how long until it pays off。

**Q:** Can I use "at once" here?

**A:** 可以。`at once` = right away，正式一档，日常叙述里两个都对；C115 已覆盖"立刻"和"同时"两支。

## Worth Stealing

> The express industry is so competitive that delivering packages correctly really matters to the companies.

The `so ... that` frame is the one that turns an opinion into a cause, and it
arrived one word short of working. Add the `so` and the sentence carries an
argument instead of a claim.
