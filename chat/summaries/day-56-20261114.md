## Questions About English

These did not count as exchanges.

**Q:** "I'm not halfway through yet" 有办法用 still hasn't (done X) by then 改写吗？

**A:** 有，但必须先立一个"那时"，否则不能上 `by then`。只说现在：I still haven't got halfway through it. 有锚点时：By last Sunday, I still hadn't got halfway through it. / By the end of this week, I still won't have got halfway through it. 模板是 `By + 时间点, 主语 + had/has/have + done`。另外 `halfway through` 是状态，用 be / get halfway through，不用 have been halfway through。

**Q:** "…but by then I still won't have got halfway through it." 能不能表达"我计划这周读完，但现在还没读一半"？

**A:** 不能。`won't have got` 是将来完成，把"还没"锁在周末那一刻；"到现在"锁在现在。三句对照：现在 I planned to finish it by the end of this week, but I'm still not halfway through. 到期预测 …but by then I still won't have got halfway through it. 计划还有效 I plan to finish it this week, but I'm not halfway through yet.

**Q:** by now 应该怎么用？

**A:** `by now` = 到此刻为止，带"按理说这会儿该已经…"的意味，常配 should / must / will have 或完成时：The train should be here by now. / By now you should have finished chapter three. / I've read it twice by now. 对照：`yet` 是否定和疑问句尾的"还没"，`now` 就是现在。

**Q:** "到现在我还没读一半" 不能用 perfect tense 吗？

**A:** 能用，动词要是个"事件"：I haven't got halfway through it yet. / I haven't read half of it yet. 状态不行：✗ I haven't been halfway through yet. → ✓ I'm not halfway through yet. 同理 be tired / be ready / be here 都用一般现在 + yet。
