**Codex:** Everyone's got one - some hobby or project you've been telling yourself you'll get into for months. You even looked up what gear you'd need. And then nothing happened. What's yours?

**You:** Yeah, I have the same feeling. I've always meant to play PC games on weekends, but I never get round to it. I have a set of advanced devices which can run the latest games, but I just want to sleep or watch short videos whenever I'm free.

/ [bookish] "a set of advanced devices which can run the latest games" -> "a rig that can run anything" - devices is for phones and gadgets; advanced is spec-sheet English.
/ [calque] "I have the same feeling" -> "Yeah, same here" / "I know the feeling" - word-for-word from the Chinese; the English is shorter.
/ [awkward] "watch short videos" -> "scroll Douyin" / "watch reels" - short videos is the category name, not what people say they are doing.
